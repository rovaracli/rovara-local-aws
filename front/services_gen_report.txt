Shared signing names: how the members of each are told apart (services_gen.go, aws-emulator@1.0.337)
Order of the signals the front reads: the SigV4 scope names the route key; then the wire protocol (the protocols the member speaks);
then the operation (X-Amz-Target operation, Query Action, CBOR path operation, or the REST method and URI template);
then the awsJson target prefix (exact, then without the _<date> suffix) or the Query Version; then the most specific REST template;
then the verified tie-break for the route key. What is still more than one member is refused.
